# 🚀 GitSense AI

AI-Powered GitHub Productivity Analyzer

## 📌 Overview

GitSense AI is an intelligent developer analytics platform that analyzes GitHub profiles using AI-driven insights and repository analytics.

The platform helps evaluate:
- Developer activity
- Repository quality
- Technology usage
- Open-source contribution patterns
- AI-generated developer insights

---

## 🔥 Features

✅ GitHub Profile Analysis  
✅ Repository Analytics  
✅ AI Developer Scoring  
✅ Most Used Language Detection  
✅ Interactive Charts & Visualizations  
✅ AI-Based Developer Insights  
✅ Modern Dashboard UI  

---

## 🛠️ Tech Stack

- Python
- Streamlit
- GitHub REST API
- Plotly
- Pandas

---

## 📊 Functionalities

### 🔹 GitHub Profile Fetching
Fetches:
- Profile image
- Followers
- Repository count
- Bio
- GitHub link

### 🔹 Repository Analysis
Analyzes:
- Top repositories
- Stars
- Forks
- Languages used

### 🔹 AI Insights
Generates intelligent developer summaries based on:
- Repository activity
- Contribution patterns
- Technology stack
